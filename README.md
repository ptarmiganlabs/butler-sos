Butler SOS is an open source DevOps monitoring tool for Qlik Sense Enterprise on Windows. It
collects real-time operational metrics from Sense and sends them to InfluxDB, Prometheus, New Relic
or MQTT, ready for dashboards and alerts. Adapt it to your needs, and please consider sharing
enhancements with the wider community.
